# RaceDay — Part 1

## System Description
RaceDay is a planned full-stack web-based event management system for the South African road running, walking and cycling community.

## Roles
**Organiser:** creates, edits and deletes events, manages categories, captures results and views event enrolments.

**Participant:** creates an account, browses events, enters an event by category, views own enrolments and tracks personal results.

## Database
The SQL Server database is `RaceDayDB`. The ERD and SQL script use the same six entities: Users, UserProfiles, Events, Categories, Enrolments and Results.
